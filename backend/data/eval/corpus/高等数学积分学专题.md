# 高等数学：积分学专题

## 不定积分

不定积分是求导的逆运算，`∫f(x)dx = F(x) + C`（F' = f，C 为任意常数）。

基本积分表（在求导公式基础上取逆）：
- `∫x^n dx = x^(n+1)/(n+1) + C`（n ≠ -1）
- `∫1/x dx = ln|x| + C`
- `∫e^x dx = e^x + C`，`∫sin x dx = -cos x + C`

两类换元法：
1. **第一类（凑微分）**：把被积表达式的一部分凑成 `d[g(x)]`，令 u = g(x) 化简，如 `∫2x·cos(x²)dx = ∫cos(u)du`
2. **第二类（三角/根式代换）**：含 `√(a²-x²)` 令 x = a·sin t，把根式消掉

**分部积分**：`∫u dv = uv - ∫v du`，用于被积函数是两类函数乘积的情形（如多项式×指数、多项式×三角、指数×三角）。选 u 的口诀"反对幂指三"——优先把排在前面的类别选作 u。

## 定积分与牛顿-莱布尼茨公式

定积分 `∫[a,b] f(x)dx` 是黎曼和的极限，几何上表示曲边梯形的有向面积。

**牛顿-莱布尼茨公式**：若 F' = f 在 [a,b] 连续，则 `∫[a,b] f(x)dx = F(b) - F(a)`——把求极限的定积分化为求原函数，是整个积分学的枢纽。

推论：
- 积分中值定理：连续函数在区间上必有一点 ξ 使积分值 = f(ξ)·(b-a)
- 变限积分 `Φ(x) = ∫[a,x] f(t)dt` 求导得 f(x)（f 连续时），是联系微积分两大部分的桥梁
- **微元法**：把非均匀总量切成微元 dQ = f(x)dx 再积分，用于求功、水压力、转动惯量等

## 反常积分（广义积分）

积分区间无限或被积函数无界时的推广：
1. **无穷限**：`∫[1,+∞) 1/x^p dx`——p > 1 收敛，p ≤ 1 发散（p 积分判别基准）
2. **瑕积分**：被积函数在某点附近无界（如 `∫[0,1] 1/√x dx`），把瑕点当无穷限处理后同样用极限判敛

判敛思路：先用比较判别法与 p 积分对比量级，再用绝对收敛推出收敛（绝对收敛的反常积分必收敛，反之不然）。
