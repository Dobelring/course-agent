# 高等数学：级数判别法专题

## 数项级数的收敛性

级数 `Σa_n` 的收敛性由**部分和数列** `S_n = a_1 + … + a_n` 的极限是否存在决定：S_n 有极限则收敛，否则发散。

必要条件（不充分！）：`Σa_n` 收敛 ⇒ `a_n → 0`。反过来不成立——调和级数 `Σ1/n` 通项趋于 0 但发散（用比较或积分判别可证）。

## 正项级数判别法

通项非负时，常用判别法按"从简单到精细"排列：

1. **比较判别法**：与已知敛散性的级数比大小，`a_n ≤ b_n` 且 Σb_n 收敛 ⇒ Σa_n 收敛；等价形式是比值极限比较
2. **比值判别法（达朗贝尔）**：`lim a_(n+1)/a_n = ρ`，ρ < 1 收敛，ρ > 1（含趋于无穷）发散，ρ = 1 失效
3. **根值判别法（柯西）**：`lim ⁿ√a_n = ρ`，结论同上，适合含 n 次方的通项
4. **积分判别法**：通项可写成 f(n) 且 f 单调递减非负，级数与 `∫f(x)dx` 同敛散

失效情形（ρ = 1）需要回到比较判别法或具体分析，典型如 p 级数 `Σ1/n^p`：p > 1 收敛、p ≤ 1 发散。

## 交错级数与莱布尼茨判别法

形如 `Σ(-1)^(n-1) · b_n`（b_n > 0）的交错级数，**莱布尼茨判别法**给出收敛的充分条件：
1. `b_n` 单调递减
2. `b_n → 0`

两个条件缺一不可；注意它只是充分条件，不满足时不能直接断言发散。

## 绝对收敛与条件收敛

- **绝对收敛**：`Σ|a_n|` 收敛。绝对收敛的级数一定收敛（柯西收敛准则可证）
- **条件收敛**：`Σa_n` 收敛但 `Σ|a_n|` 发散，如交错调和级数 `Σ(-1)^(n-1)/n`

重要推论：绝对收敛级数可任意重排求和不改结果；条件收敛级数按不同顺序重排可得到任意和（黎曼重排定理）——交换律只对绝对收敛成立。

## 幂级数与收敛半径

`Σa_n·x^n` 在原点周围存在收敛区间：
- **阿贝尔定理**：若在 x₀ ≠ 0 处收敛，则对 |x| < |x₀| 绝对收敛——收敛域必是以 0 为中心的区间
- **收敛半径**：`R = 1/lim |a_(n+1)/a_n|`（或 `1/lim ⁿ√|a_n|`），R = 0 只在原点收敛，R = +∞ 全体实数收敛
- 端点 x = ±R 处收敛性可能不同，必须**单独代入判别**，最终收敛区间要写明端点情况
