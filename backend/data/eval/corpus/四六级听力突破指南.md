# 四六级听力突破指南

## 题型概览

- 四级：短篇新闻（3 篇）+ 长对话（2 篇）+ 听力篇章（3 篇）
- 六级：长对话（2 篇）+ 听力篇章（2 篇）+ 讲座/讲话（3 篇）

共同点：**录音只放一遍**，音频结束后直接收答题卡——所有决策必须在听的过程中完成。

## 听前：选项预读

抢在播放 direction 的时间里快速浏览四个选项，是听力最核心的得分动作：
- **预测主题**：选项的共同话题提示对话场景（选课、图书馆、健康、工作面试……），大脑提前加载相关词汇
- **预判设问**：选项都是地点则问 where，都是数字时间则准备捕捉具体数据
- **划差异**：四个选项中不同的词往往是区分点，重点留意这些词的同义替换
- 实操：每题预读 8~12 秒，来不及时优先看长选项的差异词

## 听中：信号词与笔记

- **转折即考点**：but / however / actually 之后几乎必出答案
- **首尾出题**：对话开头的寒暄后第一句、结尾的约定或建议常被直接考查
- **数字与专有名词**速记：价格、时间、人名地名用缩写或符号记在选项旁
- 笔记不求全，只记"预读时预判会考"的类别：时间、地点、原因、态度
- 没听清的题立刻放弃往下看，**沉没成本不能连累下一题**

## 同义替换是核心考点

正确选项极少照搬录音原词，几乎都是**同义改写**：
- 词汇替换：book → reserve，expensive → cost a lot
- 句式转换：录音主动句，选项被动句；录音具体例子，选项抽象概括
- 归纳提炼：录音连说三件事，选项总结为一个主题词

训练方法：对答案时**把每个正确选项对应的录音原句抄下来**，标注替换点——积累替换词对是提分最快的路径。

## 精听训练法

1. 选真题音频，盲听一遍做题
2. 逐句听写：听不懂的句子反复播放 3 遍，仍写不出再看原文
3. 对照原文标出失分原因：生词、连读、语速、走神
4. 跟读模仿语音语调，培养语感后再做下一套

泛听（播客、新闻）用于磨耳朵保持语感，但**出分靠精听**——不逐句抠懂的泛听只是背景音。
