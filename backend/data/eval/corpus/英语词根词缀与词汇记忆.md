# 英语词根词缀与词汇记忆

## 词根词缀：构词法的三块积木

英语单词 = **前缀**（方向/否定）+ **词根**（核心义）+ **后缀**（词性）：
- 前缀：`pre-`（前，predict 预言）、`re-`（再/回，return、review）、`un-/dis-`（否定）、`inter-`（之间，international）、`trans-`（跨越，transport）
- 后缀：`-tion/-ment/-ity`（名词）、`-ize/-ify`（动词）、`-ive/-al`（形容词）、`-ly`（副词）
- 词根：`spect`（看，inspect 检查 / respect 尊重 / prospect 前景）、`duct`（引导，conduct / produce / educate）、`port`（搬运，export / import / transport）、`vis`（看，vision / visible）

掌握约 200 个高频词根词缀，能推断数千个派生词的含义与词性——阅读中遇到生词先拆解再猜，比直接查词典印象深。

## 一词多义与搭配

- 多义词以**常见义**为锚，生僻义由本义引申推导（如 run：跑 → 经营 → 运行）
- 记搭配而非孤立单词：`make a decision` 而非 do a decision；`heavy rain` 而非 big rain
- 动词看介词搭配：depend on、contribute to、result in/from

## 高频易混词辨析

| 词 A | 词 B | 区分点 |
|------|------|--------|
| affect | effect | A 动词（影响），E 名词（效果）；记"E-noun" |
| adapt | adopt | adapt 适应（a 像张开适应）、adopt 采纳/收养（o 像收进来） |
| principal | principle | principal 校长/主要的（含 pal 伙伴）、principle 原则（含 le） |
| complement | compliment | 互补（完成对方）vs 赞美（说好话） |

## 间隔重复记忆法

遗忘曲线揭示：新学的词若不复习，一天后忘掉约三分之二。
- **间隔重复**：按 1 天 → 3 天 → 7 天 → 15 天 → 30 天的递增间隔复习，每次都在即将遗忘时巩固
- 工具化：Anki 等卡片软件自动按算法安排到期卡片，每天固定 15~20 分钟
- 卡片正面放**英文单词或例句**，背面放中文义与一个自己造的句子——自造句的记忆强度远高于背词书释义

## 主动词汇与被动词汇

- **被动词汇**：阅读时能认出——通过大量阅读自然扩张
- **主动词汇**：写作口语能用出来——只需重点积累数百个，通过仿写与造句激活
- 备考策略：阅读靠被动词汇量打底，写作刻意把新词放进练习中用过三次以上才算掌握
