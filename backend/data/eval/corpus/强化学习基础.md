# 强化学习基础

## 马尔可夫决策过程（MDP）

强化学习的数学框架，五个要素：
- **状态集 S**、**动作集 A**
- **奖励函数 R(s,a)**：执行动作的即时反馈
- **状态转移概率 P(s'|s,a)**：在 s 执行 a 后到达 s' 的概率
- **折扣因子 γ ∈ [0,1)**：未来奖励的现值权重，γ 越小越"短视"

目标不是最大化单步奖励，而是最大化**累积折扣回报**的期望。

## 值函数与贝尔曼方程

- 状态值函数 V(s)：从 s 出发遵循某策略的期望回报
- 动作值函数 Q(s,a)：在 s 执行 a 后再遵循该策略的期望回报

**贝尔曼方程**把值函数写成"即时奖励 + 折扣后的后继值"：
`V(s) = E[R + γ·V(s')]`

最优值函数满足 Bellman 最优方程，对 Q 同理——整套动态规划算法（值迭代、策略迭代）都建立在它之上。

## Q-Learning

表格型算法，维护 Q 表并在交互中更新：

`Q(s,a) ← Q(s,a) + α · [r + γ·max_a' Q(s',a') - Q(s,a)`

- `α` 学习率，方括号是**时序差分误差**（实际奖励+估计 vs 原估计）
- 关键性质：目标取 `max Q(s',a')`，评估的是**最优动作**的价值而非当前策略的——属于 **off-policy**，行为策略与学习目标解耦
- 配合充分探索与所有状态-动作对被访问，Q 表最终收敛到最优 Q*

## 探索与利用的矛盾

- **利用**：选当前 Q 值最大的动作，稳拿眼前收益
- **探索**：试从未选过的动作，可能发现长期更优的路径
- 只利用会困在初始估计的次优策略上；只探索永远不积累可靠的价值估计

**ε-贪心**：以 1-ε 概率取当前最优动作，ε 概率随机探索。ε 随训练衰减（先广撒网后收敛）。进阶方案：UCB（按置信上界选择）、汤普森采样。

## 从表格到函数逼近

真实问题状态空间巨大，Q 表存不下——用参数化函数 Q(s,a;θ) 近似，θ 用梯度下降学，即**深度强化学习**：
- DQN：经验回放缓冲 + 目标网络，稳定训练
- 策略梯度类：直接参数化策略并沿期望回报梯度上升；Actor-Critic 结构用一个网络评价值函数降低方差
