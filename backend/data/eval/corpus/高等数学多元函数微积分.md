# 高等数学：多元函数微积分

## 多元函数的极限与连续

二元函数 f(x,y) 在点 (x₀,y₀) 的极限要求沿**任意路径**趋近时函数值都趋于同一值：
- 沿一条路径趋于 L 只能说明"可能不收敛"（用于证发散：找两条路径得不同极限即可）
- 一元函数极限存在与路径无关是平凡的，多元函数这成为实质要求

连续的定义与一元类似：极限值等于函数值。

## 偏导数与全微分

偏导数 `∂f/∂x`：固定其他自变量，对 x 求导——几何意义是曲面被平面 y = y₀ 截出的曲线在该点的斜率。

全微分：若 `Δz = A·Δx + B·Δy + o(ρ)`（ρ = √(Δx²+Δy²)），则 f 可微，`dz = (∂f/∂x)dx + (∂f/∂y)dy`，A、B 恰为两个偏导数。

**可微、偏导存在、连续的关系**（与一元"可导⇔可微"完全不同）：
- 可微 ⇒ 偏导存在，且可微 ⇒ 连续
- 偏导存在 ⇏ 可微（偏导只监控两条坐标方向，可微要求所有方向）
- 偏导存在 ⇏ 连续（反例：f 在坐标轴上取 1、其余处取 0，两偏导均为 0 但函数不连续）

判定可微的实用方法：先检查偏导是否连续——**偏导连续是可微的充分条件**；不连续时回到全增量定义验证。

## 复合与隐函数求导

- 链式法则：多元复合用**树形图**逐条路径求导再相加，变量多时按依赖关系画图防止漏项
- 隐函数：对方程 `F(x,y) = 0` 两边关于 x 求导，把 y 视为 x 的函数，解出 `dy/dx = -F_x/F_y`

## 多元极值与条件极值

驻点（两偏导同时为 0）是极值的必要不充分条件。判别用 Hessian 行列式：
- `f_xx·f_yy - (f_xy)² > 0`：f_xx > 0 极小、f_xx < 0 极大
- < 0：鞍点；= 0：判别法失效需另法

**条件极值**用**拉格朗日乘数法**：求 f(x,y) 在 g(x,y)=0 下的极值，构造 `L = f + λ·g`，解方程组 L_x = L_y = L_λ = 0。几何意义：极值点处 f 与 g 的等值线相切、梯度共线。多约束时叠加多个乘子项。

## 二重积分

- 化**累次积分**：先 y 后 x 或先 x 后 y，画出积分区域定限是关键
- **极坐标变换**：区域含圆扇形或被积函数含 x²+y² 时，`dxdy = r·drdθ`
- **对称性**：区域关于某轴对称且函数关于该变量为奇函数时积分为 0，偶函数时折半计算
