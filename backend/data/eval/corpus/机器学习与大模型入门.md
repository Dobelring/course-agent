# 机器学习与大语言模型入门讲义

## 第一章 机器学习基础
机器学习是让计算机从数据中自动学习规律的方法，主要分为三类：
- 监督学习：数据带标签，目标是学习输入到输出的映射。分类（预测类别）与回归（预测数值）是典型任务。
- 无监督学习：数据无标签，常见任务是聚类（如 K-means）与降维（如 PCA）。
- 强化学习：智能体通过与环境交互、根据奖励信号优化策略，典型应用是游戏 AI 与机器人控制。

模型评估：训练集拟合、验证集调参、测试集给出最终成绩，三者必须分离以防数据泄漏。
过拟合表现为训练误差低、测试误差高，解决方法包括增加数据、正则化（L1/L2）、 dropout、早停。
欠拟合则模型容量不足，可通过增加特征、增大模型、减少正则化来改善。

偏差-方差权衡：高偏差对应欠拟合，高方差对应过拟合，理想模型在两者间取得平衡。

## 第二章 神经网络与深度学习
神经网络由输入层、隐藏层、输出层组成，每层包含多个神经元，神经元对输入加权求和后经过激活函数（ReLU、Sigmoid、Tanh）非线性变换。
反向传播算法（BP）利用链式法则计算损失对每个权重的梯度，再由优化器（SGD、Adam）更新参数。
卷积神经网络（CNN）通过卷积核提取局部特征，适用于图像任务；循环神经网络（RNN/LSTM）处理序列数据，但存在长程依赖问题。
Transformer 架构用自注意力机制（Self-Attention）并行建模序列中任意两个位置的关系，彻底取代了循环结构，是当今大模型的基础。

## 第三章 大语言模型（LLM）
大语言模型是基于 Transformer 的超大规模神经网络，通过预训练学习语言的统计规律。
预训练 + 微调范式：先在海量文本上做无监督预训练（学习通用语言能力），再用指令数据微调对齐人类偏好（SFT）与人类反馈强化学习（RLHF）。
分词（Tokenization）：模型不直接处理字符，而是把文本切成 token，常见算法有 BPE（字节对编码）。
上下文窗口（Context Window）：模型一次能处理的最大 token 数，从 4K 到百万级不等，超出窗口的信息无法被注意。
幻觉（Hallucination）：模型可能生成看似合理但与事实不符的内容，缓解手段包括检索增强（RAG）、引用溯源与事实性评测。

## 第四章 Agent 与工具调用
AI Agent 是以 LLM 为大脑、能自主规划并调用工具完成目标的系统，核心循环为：感知 → 推理 → 行动 → 观察。
ReAct 模式让模型交替输出推理（Thought）与行动（Action），根据观察结果决定下一步。
工具调用（Function Calling）：模型输出结构化的工具名与参数，由外部系统执行并返回结果，模型再据此继续作答。
规划（Planning）：复杂任务先分解为子任务列表，再逐步执行，失败时进行重规划（Replanning）。
反思（Reflection）：对中间结果自我检查与修正，可提升长任务的成功率。
MCP（Model Context Protocol）是连接模型与工具/数据源的开放协议，把业务能力封装为标准工具服务，实现一次开发、多处复用。

## 第五章 检索增强生成（RAG）
RAG 通过"先检索、再生成"让 LLM 基于外部知识作答，减少幻觉：
1. 离线索引：文档切片（chunking）→ 向量化（embedding）→ 写入向量库
2. 在线查询：问题向量化 → 相似度检索 top-k → 重排（rerank）→ 拼入提示词 → 生成答案
常用向量检索度量是余弦相似度；混合检索（向量 + 关键词 BM25）能兼顾语义与精确匹配。
生成阶段要求模型仅依据检索片段作答并标注引用来源，检索不到时明确说"资料中未找到"。
