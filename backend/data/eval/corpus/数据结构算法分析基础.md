# 数据结构：算法分析基础

## 渐进符号

算法复杂度用渐进符号描述输入规模 n 增长时的量级：
- `O(f(n))`：上界——存在常数 c 和 n₀，n>n₀ 时 T(n) ≤ c·f(n)，"最慢不会超过"
- `Ω(f(n))`：下界，"最快不会低于"
- `Θ(f(n))`：上下界同阶，即 Θ = O ∩ Ω

同一算法常有三种复杂度：最好情况（如快排已有序退化）、最坏情况（保证的上界）、平均情况（随机输入下的期望，实际性能的更好预测）。工程讨论默认报**最坏情况**。

## 复杂度分析要点

- 时间：抓住随 n 增长的循环层数与递归调用规模，常数与低阶项在渐进意义下忽略
- 空间：除输入外额外占用的内存（递归栈、辅助数组）；原地算法指额外空间 O(1)
- 嵌套循环不等于 n²：内层循环起点/终点若随外层变化（如双指针、均摊收缩），要按实际执行次数求和再取渐进

## 递推式求解

递归算法的复杂度写成递推式，三种常用解法：

1. **代入法**：猜测形式后用归纳法证明
2. **递归树**：把 T(n) 展开成树，逐层求和再汇总各层代价
3. **主定理**：对 `T(n) = a·T(n/b) + f(n)`（a≥1, b>1）直接套结论：
   - f(n) 比 `n^(log_b a)` 低阶 → T(n) = Θ(n^(log_b a))（叶子代价主导，如二叉树遍历）
   - f(n) 与之同阶 → T(n) = Θ(f(n)·log n)（如归并排序）
   - f(n) 高阶且正则性条件成立 → T(n) = Θ(f(n))

## 摊还分析

对一串连续操作做**整体**分析，把偶发的高代价操作摊到廉价操作上：
- 动态数组（如 Python `list`）扩容：单次扩容 O(n)，但每次扩容前都攒了 Ω(n) 次 O(1) 追加，均摊后每次插入仍是 O(1)
- 三种方法：聚合分析（总代价/次数）、记账法（预付存储）、势能法（定义状态势能函数）

## 时空权衡

- 用空间换时间：预处理出查找表、哈希索引，查询从 O(n) 降到 O(1)
- 用时间换空间：压缩存储、即时计算，省内存但每次访问变慢
- 选型判据：约束是内存还是延迟，决定往哪边换
