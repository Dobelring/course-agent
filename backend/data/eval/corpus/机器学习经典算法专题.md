# 机器学习经典算法专题

## 线性回归

假设目标是输入特征的线性组合 `ŷ = w·x + b`，用**最小二乘**拟合：最小化均方误差 `MSE = (1/n)Σ(y - ŷ)²`。
- 解法：正规方程闭式解（特征少时），或**梯度下降**沿负梯度方向迭代更新权重
- 实践要点：特征量纲差异大时先标准化，否则损失等高线变狭长椭圆、下降变慢

## 逻辑回归

分类模型：在线性输出上套 **Sigmoid** 函数 `σ(z) = 1/(1+e⁻ᶻ)` 把实数压到 (0,1)，解释为正类概率。
- 损失函数用**对数损失**（交叉熵）而非 MSE——MSE 配 Sigmoid 会导致梯度消失、优化困难
- 决策边界：P ≥ 0.5 判正类（阈值可按业务代价调整）
- 可推广为多分类 Softmax 回归

## 决策树

按特征递归划分数据：每次选"分得最纯"的分裂点——
- **信息增益**：基于熵 `H = -Σp·log p`，划分前后熵下降最多
- **基尼不纯度**：`Gini = 1 - Σp²`，计算更快，CART 默认使用

停止条件：达到最大深度、叶节点样本数不足、纯度增益低于阈值。
- **剪枝**：预剪枝训练时提前停、后剪枝先长满再自底向上裁掉低价值子树，都能提升泛化
- 优点是可解释（if-then 规则）、无需特征缩放；缺点是深树容易记住训练数据的噪声

## 支持向量机（SVM）

寻找把两类分开且**间隔最大**的超平面：只由离边界最近的"支持向量"决定，其余样本点不影响模型。
- 软间隔：允许部分样本违反约束（惩罚系数 C），应对噪声与不可分
- **核技巧**：在高维空间等价计算内积而不显式升维（线性核、多项式核、RBF 高斯核），解决线性不可分

## K-means 聚类

无监督划分：随机选 K 个中心 → 每个样本归入最近中心 → 重新计算各簇均值 → 重复至中心不再变化。
- 对初始中心敏感：用 K-means++ 初始化或多次随机取最优
- K 的选择：肘部法（畸变随 K 下降的拐点）、轮廓系数
- 局限：只能发现凸形簇，簇大小/密度差异大时效果差

## 主成分分析（PCA）

把数据投影到方差最大的方向组合上实现降维：
1. 特征标准化（零均值化）
2. 计算协方差矩阵，取其特征值与特征向量
3. 按特征值从大到小选前 d 个特征向量作为新坐标轴
4. 原数据投影到新坐标系

应用：高维数据可视化（降到 2/3 维）、去相关、压缩；核 PCA 可处理非线性结构。

## 集成学习

- **Bagging**（并行）：对样本有放回重采样训练多个基模型再投票/平均；代表**随机森林**（分裂时只考虑随机特征子集，进一步降低相关性）
- **Boosting**（串行）：后一个模型重点拟合前序模型的残差/错分样本；代表 AdaBoost、GBDT、XGBoost
