# 高等数学（微积分）要点整理

## 第一章 函数与极限
函数是两个数集之间的对应关系。基本初等函数包括幂函数、指数函数、对数函数、三角函数与反三角函数。
数列极限的 ε-N 定义：对任意 ε>0，存在正整数 N，当 n>N 时 |x_n - a|<ε。
函数极限的 ε-δ 定义：对任意 ε>0，存在 δ>0，当 0<|x-x_0|<δ 时 |f(x)-A|<ε。

极限的四则运算法则要求参与运算的每个极限都存在；无穷小乘以有界量仍为无穷小。
两个重要极限：
1. lim(x→0) sin x / x = 1
2. lim(x→∞) (1 + 1/x)^x = e

等价无穷小替换（x→0 时）：sin x ~ x，tan x ~ x，1 - cos x ~ x²/2，ln(1+x) ~ x，e^x - 1 ~ x。
注意：等价无穷小替换只能用于乘除运算，不能用于加减运算中的部分项。

## 第二章 连续与间断
函数 f(x) 在 x_0 连续的条件：f(x_0) 有定义、lim f(x) 存在、lim f(x) = f(x_0)。
间断点分两类：第一类（左右极限都存在，可去间断点与跳跃间断点）、第二类（至少一个极限不存在，如无穷间断点、振荡间断点）。
闭区间上连续函数的性质：有界性、最值定理、零点定理、介值定理。
零点定理：若 f 在 [a,b] 连续且 f(a)·f(b)<0，则至少存在一点 ξ∈(a,b) 使 f(ξ)=0。

## 第三章 导数与微分
导数定义：f'(x_0) = lim(Δx→0) [f(x_0+Δx) - f(x_0)] / Δx。
可导必连续，连续不一定可导（如 y=|x| 在 x=0 处）。
求导法则：和差积商法则、复合函数链式法则。
常用导数：(x^n)' = nx^(n-1)，(e^x)' = e^x，(ln x)' = 1/x，(sin x)' = cos x。
微分 dy = f'(x)dx 是函数增量的线性主部，可导是可微的充要条件。

## 第四章 中值定理与导数应用
罗尔中值定理：f 在 [a,b] 连续、(a,b) 可导且 f(a)=f(b)，则存在 ξ 使 f'(ξ)=0。
拉格朗日中值定理：f'(ξ) = [f(b) - f(a)] / (b - a)。
柯西中值定理是拉格朗日的推广，是洛必达法则的理论基础。

洛必达法则：对 0/0 或 ∞/∞ 型未定式，若 lim f'/g' 存在，则 lim f/g = lim f'/g'。
使用前提：必须先判断类型，且求导后的极限存在或为无穷。

泰勒公式：f(x) = f(x_0) + f'(x_0)(x-x_0) + f''(x_0)(x-x_0)²/2! + … + R_n(x)。
麦克劳林公式是 x_0 = 0 的特殊情形，常用展开：e^x、sin x、cos x、ln(1+x)、(1+x)^α。

导数应用：单调性看 f' 符号，极值点出现在 f'=0 或不可导点，凹凸性看 f'' 符号，渐近线分水平、垂直、斜三种。
