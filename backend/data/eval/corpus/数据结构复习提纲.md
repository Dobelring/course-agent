# 数据结构期末复习提纲

## 第一章 线性表
线性表是 n 个同类型元素的有限序列，有顺序存储（数组）与链式存储（链表）两种实现。
顺序表支持 O(1) 随机访问，但插入删除需要移动元素，平均 O(n)；
单链表插入删除只需修改指针 O(1)，但按位查找需要从头遍历 O(n)。
双向链表每个结点增加前驱指针，可双向遍历；循环链表尾结点的 next 指向头结点。

## 第二章 栈与队列
栈是后进先出（LIFO）结构，典型应用：函数调用栈、括号匹配、表达式求值、深度优先搜索。
队列是先进先出（FIFO）结构，典型应用：广度优先搜索、消息缓冲、打印机任务队列。
循环队列通过 `(rear + 1) % capacity == front` 判断队满，牺牲一个存储单元区分队空与队满。

## 第三章 树与二叉树
二叉树的性质：第 i 层至多有 2^(i-1) 个结点；高度为 h 的二叉树至多有 2^h - 1 个结点。
遍历方式：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）、层序（按层 BFS）。
已知前序与中序、或后序与中序序列可唯一还原二叉树，仅有前序与后序不行。
二叉搜索树（BST）左子树所有键小于根、右子树所有键大于根，中序遍历得到有序序列。
平衡二叉树（AVL）要求任意结点左右子树高度差不超过 1，通过旋转操作维持平衡。

## 第四章 图
图的存储：邻接矩阵 O(V^2) 空间、邻接表 O(V+E) 空间，稀疏图首选邻接表。
遍历：DFS 用栈或递归，BFS 用队列。
拓扑排序适用于有向无环图（DAG），用于任务调度与课程先修关系判定，O(V+E)。
最小生成树：Prim 适合稠密图，Kruskal 适合稀疏图（按边权排序 + 并查集判环）。
最短路径：Dijkstra 不允许负权边，Bellman-Ford 可检测负权环，Floyd 求任意两点间 O(V^3)。

## 第五章 排序算法
| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|---------|---------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

快速排序通过一趟划分将待排序列分成独立两部分，是实际应用中最快的通用排序算法之一。
归并排序稳定且最坏情况仍为 O(n log n)，常用于外部排序与链表排序。

## 第六章 查找
顺序查找 O(n)；折半查找要求线性表有序且支持随机访问，O(log n)。
哈希表通过散列函数将键映射到桶，处理冲突的方法：开放定址法（线性探测、二次探测）与链地址法。
装填因子 α = 表中记录数 / 表长，α 越大冲突越多，查找平均长度随之增长。
