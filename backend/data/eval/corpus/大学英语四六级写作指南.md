# 大学英语四六级写作与翻译指南

## 写作结构模板
四六级作文一般采用三段式结构：
第一段（引出话题）：用现象描述或数据引出主题，改写题目关键词，表明个人观点。
第二段（论证展开）：给出 2-3 个分论点，每个分论点配一句解释和一个例子，注意使用衔接词。
第三段（总结升华）：重申观点，提出建议或展望，避免引入新论点。

常用衔接词：
- 递进：furthermore, moreover, in addition
- 转折：however, nevertheless, on the contrary
- 因果：therefore, as a result, consequently
- 举例：for instance, to illustrate, take...as an example

## 高分句型
1. 倒装句：Only by doing so can we solve the problem effectively.
2. 强调句：It is persistence that leads to ultimate success.
3. 非限定性定语从句：As is vividly depicted in the picture,...（图画作文万能开头）
4. 虚拟语气：Were I given a second chance, I would make a different choice.
5. 主语从句：What impresses me most is the spirit of teamwork.

## 常见作文类型
- 观点论证型：表明立场 → 分论点 → 例证 → 总结
- 现象分析型：描述现象 → 分析原因 → 预测趋势 → 给出建议
- 引语名言型：解释名言 → 联系现实 → 个人感悟
- 图画漫画型：描述图画 → 揭示寓意 → 论证观点 → 总结呼吁
- 书信应用型：开头表明写信目的 → 正文分点陈述 → 结尾期待回复

## 翻译技巧（段落翻译）
四大核心技巧：
1. 语序调整：中文多短句，英文多长句，要学会合并与拆分，使用定语从句、分词结构。
2. 词性转换：中文常用动词，英文可转为名词或介词短语，如"他来了" → His arrival。
3. 增词与减词：补充英文必需的冠词、介词；删除中文重复的修饰语。
4. 成语与文化词处理：意译优先，必要时直译加解释，如"愚公移山" → Foolish Old Man Removes the Mountains。

高频话题词汇：
- 传统文化：cultural heritage, filial piety, the Spring Festival, reunion dinner
- 科技发展：artificial intelligence, big data, mobile payment, e-commerce
- 环境保护：carbon neutrality, sustainable development, renewable energy, pollution
- 教育成长：critical thinking, well-rounded, extracurricular activities, lifelong learning

## 备考时间安排
- 第 1-2 周：背诵 20 篇范文模板，积累高频词汇与句型
- 第 3-4 周：每周精写 3 篇真题作文，对照范文批改
- 第 5-6 周：限时 30 分钟完成写作，训练翻译速度，查漏补缺
